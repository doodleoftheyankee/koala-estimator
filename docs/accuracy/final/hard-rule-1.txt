How the code keeps it (unchanged mechanism; see docs/accuracy/after-fixb/hard-rule-1.txt)
  - A stored quote's company, license, phone, terms, warranty, consent sentence, number, dates,
    items and prices are read from its own document (quotes.snapshot->document), never from the
    settings. OD12/OD13's "Koala Insulation", "Limited lifetime warranty" and neutral terms, the
    PLACEHOLDER rule and OD14's consent state apply only when a new quote is built.
  - OD15 (flow-B4) moves the recommendation only for a quote being built; a stored document keeps
    its recommendedTier, so the RECOMMENDED badge and "(recommended)" of every stored quote are as
    sent (all 231 open pages, PDFs and emails above are identical in text).
  - The accuracy migration's review B sections rewrite app_settings rows only where they still
    equal the seed, and add price_approvals.loaded_cost; no quote, snapshot, PDF or e-sign record
    is touched (tests/sql/41_owner_decisions.test.sql).

To repeat it
  1. Render the merged head: node scripts/accuracy/render-run.mjs scripts/accuracy/render-stored.ts
     <export> <after>.
  2. Render the before code: git archive 7c6b08c into a folder, copy scripts/accuracy/render-run.mjs,
     render-stored.ts and stubs/ into it (7c6b08c predates them), link node_modules, and run the
     same command there into <before>.
  3. diff -r <before> <after>, and python3 -I scripts/accuracy/hard-rule-1-diff.py <before> <after>
     to sort the differences (identical / class names only / other).
